Features

Everything you need, nothing you don't

A full AI reading and acting assistant — all running inside your browser with your own API key.

📄

Article & YouTube summaries

Structured TL;DR, five key points, and next steps — for any article or public YouTube video. Timestamps are clickable.

💬

Grounded page chat

Ask anything about the current page. Sahayak answers only from the page text and says so when the answer isn't there.

✨

Explain, Translate, Draft

Right-click any selected text to explain jargon, translate into Hindi or Hinglish, or draft a ready-to-send reply.

📸

Screenshot and ask

Capture the visible area, crop to the chart or error dialog that matters, and ask Gemini Flash a question about it.

🔢

Interactive element map

Scans every button, link, input, and dropdown on the page and overlays numbered badges so the agent can reason over them.

🎯

Find it for me

Describe what you're looking for in plain words. Sahayak rings the matching element — without clicking it.

🤖

One-step agent loop

Give Sahayak a goal. It proposes one action at a time and waits. Approve, Skip, or Stop — you're always in charge.

⚡

One-click skills

Save reusable prompt recipes — exam notes, Hinglish explainer, polite reply, form filler. Export and import as JSON.

👤

Local profile memory

Store your name, college, skills, and links locally. Sahayak uses them to personalise drafts and suggest form values.

🌐

English & Hinglish

Switch output language in the header. Every feature — summaries, chat, explanations — responds in your chosen language.

🔄

Free-tier resilience

Defaults to Gemini Flash-Lite. Backs off and retries on 429. Falls back to Groq text when Gemini is busy.

🔒

Safety in code

Banking pages, password fields, OTP inputs, and card fields are blocked by deterministic code — not just model instructions.

How it works

Get started in four steps

No cloud account, no subscription. Just Chrome and a free API key.

Download the ZIP

Grab the latest release from GitHub Releases and unzip it anywhere on your machine.

Load unpacked

Open chrome://extensions, enable Developer mode, and click Load unpacked → select the extension/ folder.

Add your API key

Get a free Gemini key from Google AI Studio and paste it into Sahayak Settings. Your key never leaves the device.

Open the side panel

Pin Sahayak, navigate to any article or practice page, and open the side panel to start summarising, chatting, and acting.

Safety first

Deterministic rules, not model prompts

Every safety restriction is enforced by extension code that runs before any model call and before any DOM write. Prompts may repeat the rules, but code is the control.

  • Password, OTP, CVV, and card fields blocked in executor before DOM write
  • Banking, UPI, and payment pages blocked before capture or model send
  • Agent restricted to practice pages or origins you explicitly own
  • Consequential actions (Submit, Pay, Send) need a second tap
  • Stop button always visible and always works
  • API keys stored locally; never committed to git
  • Profile and skills stay on-device; never synced
  • In-flight model results ignored after Stop

Sahayak will never

  • Type into a password or OTP field
  • Enter card numbers or UPI PINs
  • Automate login flows
  • Act on banking or payment pages
  • Send private pages to an external model
  • Run autonomously without approval
  • Commit API keys to the repository
